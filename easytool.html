01

特性

Features

不是一堆互不相干的小工具，而是一个可扩展的轻量框架。

F1

模块注册表架构

每个功能是独立模块，在设置页可独立启停、排序、配置。扩展新模块只需新增目录 + manifest 清单，不影响其他模块。

manifest.json · default_config
F2

全局热键

统一模式下一个热键唤起主面板；也可为各模块配置独立热键。录制器支持 Ctrl / Shift / Alt / Super 组合，热键以对象比对注册，无重复冲突。

Ctrl+Shift+E
F3

跟随鼠标弹窗

剪贴板与搜索弹窗出现在光标旁，失焦自动隐藏。弹窗延迟创建——首次呼出才建窗，不影响应用启动速度。

F4

托盘驻留

关闭主窗口即收进系统托盘，后台持续监听剪贴板、轮询额度，随时再呼出。

F5

旧数据迁移

旧版 PasteBoard 剪贴板历史（按 hash 导入）、QuotaMonitor 余额记录（按时间合并去重），启动时自动导入，幂等执行。

F6

本地优先

历史数据存本地 SQLite（WAL），密钥写入系统钥匙串、每账户独立槽位，不经过任何第三方服务器。

架构

Architecture

三层结构：壳负责窗口与热键，注册表负责模块生命周期，模块自己管自己的数据。

Shell 壳
lib.rs
托盘关闭 = 驻留 · 右键退出
全局热键Shortcut 对象比对注册
窗口管理main / 弹窗 · 延迟创建
Module Registry
模块注册表
manifest.json描述 / 默认配置 / 热键
启停 · 排序module_order 持久化
双入口模块页 + 独立弹窗
Modules
四个模块
剪贴板WM_CLIPBOARDUPDATE + 轮询

P1 / Windows

窗口体系

main 主窗口：面板模式（点外部关闭、置顶、跳过任务栏、可选跟随鼠标）；clipboard_popup / search_popup 跟随鼠标、失焦自动隐藏。全部延迟创建——首次呼出才建窗，避免启动闪现。

popup 首次呼出 → 创建窗口
→ 跟随鼠标定位 → 失焦 hide
P2 / Hotkey

热键注册

unified_hotkey=true（默认）：只注册主窗口热键，模块独立热键全部禁用；关闭则反之（主窗口改由托盘呼出）。匹配必须用对象比较，字符串格式不匹配。

Shortcut::from_str(&cfg)
  .map(|s| s == *shortcut)
P3 / Clipboard

监听链路

事件驱动（WM_CLIPBOARDUPDATE）+ 500ms 轮询兜底双路径；按内容 hash 去重，表情写入登记指纹防误记；2s 时间窗口自写守卫，不记录自己的粘贴。

event / poll → 指纹比对
→ 跳过自写 → 写库 → emit
P4 / Quota

额度轮询

后台线程 poll_loop 按 refresh_interval_sec（≥5s）逐账户查询：DeepSeek GET /user/balance；OpenCode Go GET /zen/go/v1/usage。更新状态 → 告警 → 写历史 → emit。

poll_loop → fetch_once
→ 逐账户更新 → 告警 → emit
P5 / Emoji

智能渲染

系统字体优先：canvas 像素检测（不透明/彩色像素统计）判断字符是否被支持，不支持的自动回退 Twemoji SVG，结果持久化 localStorage 跨启动复用；共享 canvas + 每帧分片队列不阻塞主线程。

字符 → 检测 → 缓存
→ 支持? 字符 : twemoji/xx.svg
P6 / Frontend

模块保活

主窗口模块切换用 keep-alive 显隐（不卸载重建），修复切页卡顿；模块页面与独立弹窗共享同一套组件，双向入口。

切页 → display 切换
→ 状态保持 · 不重载
Everything 依赖：搜索模块通过 Everything64.dll 调用系统索引（MIT 许可），SDK 有进程级全局状态，查询持全局互斥锁并放后台线程执行；未安装 Everything 时提示并尝试 -startup 自动启动（后台托盘，不弹主窗口）。

数据与安全

Data & Security

全部数据与密钥都留在本机，应用不依赖任何第三方服务器。

Config
%APPDATA%\com.aliboder.easytool\config.json — 应用配置、模块启停与排序、热键、主题
Clipboard
clipboard.db — SQLite（WAL 模式），含固定排序 pin_order；图片存 images/，缩略图存 thumbs/
Quota
balance_history_<account>.json — 各账户余额历史（旧版）；新版并入 SQLite，保留最近 5000 条
Secrets
keyring（系统钥匙串）— service com.aliboder.easytool，每账户独立槽位：deepseek / opencode-go / quota-<id>
Migration
旧版 PasteBoard 剪贴板历史按 hash 导入；旧版 QuotaMonitor 余额记录按时间合并去重；启动时自动执行一次，幂等

安装

Installation

Windows 10 / 11。安装包为 NSIS 格式，安装为当前用户，无需管理员权限。

winget 推荐

Windows 包管理器一键安装，自动处理升级。

$ winget install Aliboder.EasyTool
# 发布到 winget 仓库后可用
需要 Windows 10 1709+ 或 Windows 11 WebView2 运行时（系统自带）

GitHub Releases

从 Releases 页下载安装包，双击安装。

$ start https://github.com/Aliboder/EasyTool/releases

常见问题

FAQ
Q1文件搜索为什么需要安装 Everything？+
文件搜索模块基于 Everything 的索引引擎实现全盘秒搜，Everything 是免费的（voidtools.com，MIT 许可）。应用检测到未运行时会在搜索弹窗提示，并尝试自动启动。
Q2我的剪贴板历史和 API 密钥存在哪里？+
历史数据全部在本机 %APPDATA%\com.aliboder.easytool（SQLite + 图片文件）。密钥只写入系统钥匙串（keyring），每个账户独立槽位，任何情况下都不以明文落盘、不上传任何服务器。
Q3我原来在用 PasteBoard / QuotaMonitor，能迁移吗？+
能。启动时自动检测并导入：剪贴板历史按内容 hash 去重导入，额度记录按时间合并去重，全程幂等，重复启动不会产生重复数据。
Q4关闭主窗口后程序还在吗？+
在。关闭主窗口只是收进系统托盘，后台继续监听剪贴板、轮询额度。托盘图标右键可完全退出。
Q5热键被其他软件占用了怎么办？+
设置页可以重新录制任意热键，录制器支持 Ctrl / Shift / Alt / Super（Windows 键）组合。也可以关闭统一热键模式，改为各模块独立热键，甚至全部关闭，只用托盘呼出。
