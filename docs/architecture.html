EasyTool 架构思维导图

根节点向右展开 · 六大分支对应项目的六个关注面（按当前项目目录绘制，quicklaunch 已并入 search）

  • EasyToolWindows 桌面工具箱 · 单应用 + 模块注册表
    • 技术栈stack
      • 桌面框架Tauri 2Rust 后端 + WebView 前端
      • 前端React 19 + TSTailwind v4 · shadcn/ui · lucide-react · dnd-kit
      • 后端依赖rusqlite · keyring · reqwest · chrono
      • 构建Vite MPA多 HTML 入口，打包 nsis/msi
    • 前端界面层src/
      • 窗口入口 ×4index.html主窗 + 剪贴板/表情/搜索三个弹窗（延迟创建）
      • 应用壳App.tsx底部导航 + 设置页 + keep-alive 模块页
      • 公共设施
        • components/ui/shadcn 基础组件 · 热键录制器 · 右键菜单
        • hooks/useModuleConfig · usePopupGeometry
        • lib/api.tsIPC 封装 · theme · toast
      • 模块页面src/modules/每模块一个目录
        • clipboard/Clippage · ClipSettings
        • quota/QuotaPage · 卡片 · 汇总 · 设置
        • emoji/Page · Popup · SmartEmoji
        • search/Page · Popup · SearchView
    • 后端应用壳src-tauri/src/
      • lib.rsrun() 总入口：托盘 · 全局热键分发 · 窗口事件 · 单实例 · 日志
      • config.rsAppConfig 全局配置，读写 config.json（损坏自动备份）
      • migrate.rs旧版数据一次性迁移（幂等）
      • modules/mod.rs注册表：扫描 manifest → 合并配置 → 提供给前端
      • 启动流程读配置 → 迁移 → 启用模块并行开线程初始化 → 托盘/热键就绪
    • 四大功能模块前后端各一目录 + manifest
      • 剪贴板clipboard/
        • 监听 WM_CLIPBOARDUPDATE + 500ms 兜底轮询 · hash 去重
        • SQLite WAL 存储 · 固定 pin_order · 图片存 images/thumbs
        • 跟手粘贴（paste.rs）
      • 额度监控quota/
        • 多账户：DeepSeek / OpenCode Go，密钥各存 keyring 独立槽位
        • 后台 poll_loop 轮询 · 阈值告警 · 消费历史图表
      • 表情面板emoji/
        • emoji.json 1911 条 · 中文/英文/shortcode 搜索 · 收藏置顶
        • 文本 SendInput 直输不进剪贴板；图片走 write+Ctrl+V
      • 文件搜索search/
        • Everything64.dll 动态加载（需用户装 Everything）· 全局互斥锁查询
        • apps.rs 应用扫描 + foreground.rs 前台频率统计（原 quicklaunch 并入）
    • 数据持久层%APPDATA%\com.aliboder.easytool\
      • config.json所有设置：模块开关/顺序/热键/主题
      • *.dbSQLite WAL：剪贴板历史、额度记录
      • images/ thumbs/ easytool.log图片缓存与日志
      • Windows 凭据管理器API 密钥存系统 keyring，不落明文
    • 关键机制design decisions
      • 统一呼出unified_hotkey=true 时只注册主窗热键（默认 Ctrl+Shift+E），模块热键全禁用
      • 弹窗延迟创建首次按热键才建窗，避免启动闪现
      • keep-alive访问过的页面只隐藏不销毁，切换零等待
      • 可插拔扩展新模块 = 加目录 + manifest.json，壳代码零改动（docs/module-guide.md）
