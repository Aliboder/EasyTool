# EasyTool 性能测试指南

## 测试指标

| 指标 | 测量方法 | 目标 |
|------|----------|------|
| 冷启动时间 | 从进程启动到主窗口显示 | <1s |
| 内存占用 | 任务管理器工作集 | -20%+ |
| 首屏渲染 | 从窗口显示到内容可交互 | <1s |

## 测试场景

### 1. 冷启动测试
1. 完全退出 EasyTool（任务管理器结束进程）
2. 打开任务管理器，记录初始内存（应该接近 0）
3. 启动 EasyTool，用秒表计时
4. 记录主窗口显示时间
5. 记录稳定后内存占用（等待 10 秒）

### 2. 热启动测试
1. 启动 EasyTool
2. 最小化窗口
3. 点击托盘图标恢复窗口
4. 记录恢复时间

### 3. 长时间运行测试
1. 启动 EasyTool
2. 正常使用 1 小时（剪贴板、搜索、表情等）
3. 记录内存占用变化

### 4. 多模块场景测试
1. 禁用所有模块，测试启动时间
2. 只启用剪贴板，测试启动时间
3. 只启用剪贴板+搜索，测试启动时间
4. 启用所有模块，测试启动时间

## 测试工具

### Windows 任务管理器
- 打开任务管理器（Ctrl+Shift+Esc）
- 切换到「详细信息」标签
- 找到 EasyTool 进程
- 右键 → 添加列 → 勾选「工作集（内存）」
- 记录「工作集（内存）」列的值

### PowerShell 脚本（可选）

```powershell
# 测量启动时间
$start = Get-Date
Start-Process -FilePath "path\to\EasyTool.exe"
Start-Sleep -Seconds 1
$end = Get-Date
$duration = ($end - $start).TotalSeconds
Write-Host "启动时间: $duration 秒"

# 监控内存占用
$process = Get-Process -Name "EasyTool"
Write-Host "内存占用: $($process.WorkingSet64 / 1MB) MB"
```

### 秒表
- 手动计时：启动 EasyTool 到主窗口显示的时间

## 优化效果对比

### 优化前（v0.5.0）
- 冷启动时间：~2s
- 内存占用：基准值
- 首屏渲染：~1.5s

### 优化后（v0.5.1）
- 冷启动时间：目标 <1s
- 内存占用：目标 -20%+
- 首屏渲染：目标 <1s

## 注意事项

1. **测试环境**：在相同硬件和系统环境下测试
2. **测试次数**：每个场景测试 3 次，取平均值
3. **后台程序**：关闭不必要的后台程序，避免干扰
4. **系统状态**：重启后测试，确保系统状态一致
5. **杀毒软件**：暂时关闭杀毒软件，避免实时扫描影响
