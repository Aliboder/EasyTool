# EasyTool 工具箱实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个 Windows 桌面工具箱：Tauri 2 单应用 + 模块注册表架构，第一批包含剪贴板与额度监控两个模块，支持独立开关/配置、数据迁移、打包分发。

**Architecture:** 单 Tauri 应用 = 壳程序（托盘/窗口/配置/热键/模块注册表）+ 自包含模块（manifest + Rust 后端 + React 前端）。壳不依赖任何具体模块；模块之间不互相依赖。剪贴板模块移植 PasteBoard 的 Rust 核心（`D:\SystemFiles\Documents\Project\PasteBoard\src-tauri\src\`），额度监控模块从 C# QuotaMonitor 重写。

**Tech Stack:** Tauri 2（Rust）、React 19 + TypeScript、Tailwind CSS v4 + shadcn/ui、SQLite（rusqlite bundled）、reqwest、keyring（DPAPI）、tauri-plugin-global-shortcut / single-instance / autostart。

**Spec:** `docs/superpowers/specs/2026-08-19-easytool-design.md`

## Global Constraints

- Windows 11 为目标平台，Windows API 剪贴板操作使用 `windows` crate 0.61
- 所有用户数据在 `%APPDATA%\com.aliboder.easytool\`：`config.json`（设置）、`clipboard.db`（SQLite 剪贴板历史）、`balance_history.json`（额度记录）
- 模块清单：`src-tauri/modules/<id>/manifest.json`，含 `id/name/icon/enabled/default_config` 字段
- 密钥必须加密存储（keyring/DPAPI），禁止明文落盘
- 全局热键默认：`Ctrl+Shift+V` 剪贴板、`Ctrl+Shift+E` 主窗口
- Rust 侧必须保留的关键单元测试：去重逻辑、数据库 CRUD、告警判定（临界一次/突增 3 倍）；UI 手动验收
- 每个任务结束必须 commit
- 依赖版本对齐 PasteBoard 已验证版本：tauri 2、rusqlite 0.32 (bundled)、windows 0.61、tauri-plugin-global-shortcut 2、tauri-plugin-single-instance 2、tauri-plugin-autostart 2.5.1

改写 `src-tauri/src/lib.rs`（先删除生成的默认代码）：

```rust
use tauri::{
    menu::{Menu, MenuItem},
    tray::{MouseButton, MouseButtonState, TrayIconBuilder, TrayIconEvent},
    Manager, WindowEvent,
};

pub const MAIN_WINDOW_LABEL: &str = "main";

fn build_tray(app: &tauri::App) -> tauri::Result<()> {
    let show = MenuItem::with_id(app, "show", "显示主窗口", true, None::<&str>)?;
    let quit = MenuItem::with_id(app, "quit", "退出", true, None::<&str>)?;
    let menu = Menu::with_items(app, &[&show, &quit])?;
    TrayIconBuilder::new()
        .menu(&menu)
        .show_menu_on_left_click(false)
        .on_menu_event(|app, event| match event.id.as_ref() {
            "show" => show_main(app),
            "quit" => app.exit(0),
            _ => {}
        })
        .on_tray_icon_event(|tray, event| {
            if let TrayIconEvent::Click {
                button: MouseButton::Left,
                button_state: MouseButtonState::Up,
                ..
            } = event
            {
                show_main(tray.app_handle());
            }
        })
        .build(app)?;
    Ok(())
}

fn show_main(app: &tauri::AppHandle) {
    if let Some(win) = app.get_webview_window(MAIN_WINDOW_LABEL) {
        let _ = win.show();
        let _ = win.unminimize();
        let _ = win.set_focus();
    }
}

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_single_instance::init(|app, _args, _cwd| {
            show_main(app);
        }))
        .setup(|app| {
            build_tray(app)?;
            Ok(())
        })
        .on_window_event(|window, event| {
            // 关闭主窗口时隐藏到托盘而不是退出
            if let WindowEvent::CloseRequested { api, .. } = event {
                if window.label() == MAIN_WINDOW_LABEL {
                    window.hide().unwrap();
                    api.prevent_close();
                }
            }
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

- [ ] **Step 5: 实现模块注册表**

`src-tauri/src/modules/mod.rs`：

```rust
use std::{fs, path::PathBuf};
use serde::Deserialize;
use tauri::Manager;

#[derive(Deserialize, Clone)]
pub struct Manifest {
    pub id: String,
    pub name: String,
    pub icon: String,
    pub enabled: bool,
    pub default_config: serde_json::Value,
}

pub fn modules_dir(app: &tauri::AppHandle) -> PathBuf {
    app.path()
        .resolve("modules", tauri::path::BaseDirectory::Resource)
        .unwrap()
}

pub fn load_manifests(app: &tauri::AppHandle) -> Vec<Manifest> {
    let dir = modules_dir(app);
    let mut out = vec![];
    if let Ok(entries) = fs::read_dir(dir) {
        for e in entries.flatten() {
            if e.path().is_dir() {
                let mpath = e.path().join("manifest.json");
                if let Ok(text) = fs::read_to_string(mpath) {
                    if let Ok(m) = serde_json::from_str::<Manifest>(&text) {
                        out.push(m);
                    }
                }
            }
        }
    }
    out
}
```

在 `src-tauri/tauri.conf.json` 的 `bundle.resources` 中加入 `["modules/**/*"]`，并给 `AppConfig::default()` 的 `modules` 以 manifest 的 id/enabled 为准合并（`load_config` 完成后调用 `merge_manifests(&mut cfg, &manifests)`：manifest 中出现的 id 若不在 config 中则插入默认值并设 enabled）。
