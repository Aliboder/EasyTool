# EasyTool 设计文档

> 日期：2026-08-19
> 状态：已与用户确认

## 1. 项目定位

EasyTool 是一个 Windows 桌面工具箱软件：集成多个独立功能，每个功能可单独开关、单独配置，且架构支持持续拓展新功能。软件以系统托盘形式常驻，随时呼出使用。

第一批功能：

- **剪贴板**（移植自 PasteBoard）：剪贴板历史管理
- **额度监控**（移植自 QuotaMonitor）：DeepSeek 余额 / OpenCode Go 套餐监控

## 2. 技术栈

与 cc-switch 一致（用户指定参考其界面风格）：

- **Tauri 2**（Rust 后端 + WebView 前端），安装包 10MB 级
- **React + TypeScript**
- **Tailwind CSS + shadcn/ui**（cc-switch 的组件库来源）
- **SQLite**（数据存储）

选型理由：PasteBoard 同为 Tauri，Rust 核心逻辑（剪贴板监听、数据库、全局热键、粘贴回原窗口）可直接复用；前端换 React + shadcn/ui 以对齐 cc-switch 的视觉风格并加速后续功能开发。

## 3. 整体架构

单应用 + 模块注册表模式（方案 A，已确认）：

```
EasyTool（一个 Tauri 应用）
│
├── 壳程序（Core）
│   ├── 托盘常驻（左键呼出主窗口，右键菜单快速切换模块）
│   ├── 窗口管理（主窗口 + 各模块附加窗口）
│   ├── 配置中心（SQLite + JSON，统一读写）
│   ├── 通知 / 全局热键 / 开机自启
│   └── 模块注册表（启用状态、入口、manifest 加载）
│
├── 模块
│   ├── 📋 剪贴板（clipboard）
│   └── 📊 额度监控（quota）
│
└── 未来：新模块 = 新建目录 + 清单登记一行
```

### 模块定义

每个模块是自包含的目录，包含三部分：

1. **manifest.json**：模块清单（id、名称、图标、enabled、默认配置）
2. **Rust 侧**：模块后台逻辑，通过 Tauri command 暴露给前端
3. **前端侧**：模块页面组件 + 设置组件

### 独立开关与配置

- `enabled` 开关决定模块是否在侧边栏显示、Rust 后台是否启动
- 每个模块在配置库有独立命名空间（如 `clipboard.*`、`quota.*`），互不干扰
- 停用不删除配置，重新启用即恢复

## 4. 界面设计

### 主窗口

```
┌────────────────────────────────────────────┐
│ 侧边栏                   内容区            │
│ ┌──────────┐    ┌──────────────────────┐  │
│ │ EasyTool │    │                      │  │
│ │          │    │   当前模块的页面      │  │
│ │ 📋 剪贴板 │    │                      │  │
│ │ 📊 额度监控│    │                      │  │
│ │ ──────── │    │                      │  │
│ │ ⚙ 设置   │    │                      │  │
│ └──────────┘    └──────────────────────┘  │
└────────────────────────────────────────────┘
```

- 侧边栏：启用的模块列表（图标 + 名称），底部固定「设置」入口
- 内容区：当前模块页面；模块设置页也在内容区打开（cc-switch 的 Edit 弹窗模式）
- 主题：深色（默认）/ 浅色 / 跟随系统，可切换
- 视觉语言：圆角卡片、柔和阴影、蓝紫主色调，复刻 cc-switch（shadcn/ui）

### 托盘

- 左键单击：呼出 / 隐藏主窗口
- 右键菜单：快速切换模块、显示/隐藏各模块窗口、设置、退出

### 附加窗口

- 额度监控悬浮窗保留为独立置顶小窗，由模块自己控制开关（模块系统"窗口"能力）

### 全局热键（均可自定义）

- `Ctrl+Shift+V`：呼出剪贴板（继承 PasteBoard）
- `Ctrl+Shift+E`：呼出主窗口
- 模块可注册自己的全局热键

## 5. 模块移植方案

### 剪贴板模块（移植 PasteBoard）

- Rust 侧复用：剪贴板监听（文本/图片/文件）、SQLite 存储、全局热键、粘贴回原窗口
- 前端重写为 shadcn/ui 风格
- 功能照搬：类型筛选（全部/固定/文本/图片/文件）、一键粘贴、实时搜索、固定置顶、查看大图、`Ctrl+Shift+V` 呼出、自动去重、历史上限（默认 500）

### 额度监控模块（从 C# QuotaMonitor 重写）

C# 代码无法复用，全部重写为 Rust + React，功能清单照搬：

- 悬浮窗：实时余额、状态颜色（绿/橙/红）、悬停增亮、锁定穿透、置顶、位置记忆
- 监控源：DeepSeek 余额 / OpenCode Go 套餐（5小时/周/月 三窗口，可切换剩余/已用）
- 告警：余额低于阈值临界提醒一次（可开关）、消费突增提醒（今日 > 近 7 天日均 3 倍，每日最多一次，可开关）
- 统计面板：当前余额、今日消费、近 14 天每日消费柱状图、Go 套餐使用率进度条
- 设置：密钥管理（加密存储、测试、应用、清空）、刷新间隔（5 秒 ~ 2 分钟）、预警阈值、悬浮窗外观（字号/透明度/暗度/圆角）

## 6. 数据与迁移

- 新数据目录：`%APPDATA%\com.aliboder.easytool\`
- 首次启动检测旧数据目录，提示一次性导入（可选）：
  - PasteBoard 历史（`%APPDATA%\com.aliboder.pasteboard\`）→ SQLite 直接搬入
  - QuotaMonitor 余额记录（`文档\QuotaMonitor\`）→ JSON 解析导入
- 不导入不影响使用

## 7. 打包发布

- NSIS 安装包 + 免安装便携版（复用 PasteBoard 打包流程）
- 用户数据独立存放于各自 `%APPDATA%\com.aliboder.easytool\`
- 应用图标：设计简单中性图标（后续可更换）

## 8. 开发节奏

| 步骤 | 内容 | 预计耗时 |
|------|------|----------|
| 1 | 壳程序骨架：Tauri 搭建、侧边栏、模块注册表、托盘、主题 | 半天 |
| 2 | 剪贴板模块：Rust 复用 + 前端重写 | 1 天 |
| 3 | 额度监控模块：全部重写 | 1 天 |
| 4 | 数据迁移 + 打包发布 | 半天 |

- 验证：每步完成由用户按验证清单验收；Rust 核心逻辑写单元测试（剪贴板去重、额度告警逻辑）；UI 手动验收
- 每步完成即汇报，用户确认后进入下一步

## 9. 明确不做（保持轻量）

多语言、自动更新、云同步、拖拽排序、插件市场、PasteBoard 热键录制 UI、QuotaMonitor 界面调试模式（暂缓，稳定后视需求决定）。

## 10. 风险与约束

- WebView 依赖系统 WebView2（Win10/11 自带，基本无风险）
- 剪贴板监听需常驻进程：托盘常驻已满足
- 全局热键冲突：提供自定义热键能力缓解
