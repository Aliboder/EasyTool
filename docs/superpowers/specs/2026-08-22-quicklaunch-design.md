# 快速启动模块设计文档

## 1. 概述

快速启动模块（quicklaunch）是一个类似 Windows 11 开始菜单固定功能的模块，支持固定软件、文件、文件夹和URL，提供快速访问和组织功能。

### 1.1 核心功能
- 固定软件、文件、文件夹和URL
- 支持多级文件夹嵌套
- 混合布局（网格/列表视图切换）
- 拖拽排序
- 筛选和搜索功能
- 系统原生右键菜单

### 1.2 目标用户
- 需要快速访问常用应用和文件的用户
- 希望组织和分类快捷方式的用户

## 2. 架构设计

### 2.1 整体架构
模块采用三层架构：
1. **数据层**：SQLite 数据库存储固定项、文件夹结构和排序信息
2. **后端服务**：Rust 模块处理固定项管理、文件操作、热键响应
3. **前端界面**：React 组件，支持网格/列表视图切换，拖拽排序

### 2.2 数据流
用户操作 → 前端调用 IPC 命令 → Rust 处理业务逻辑 → 更新数据库 → 前端响应更新

## 3. 数据模型

### 3.1 数据库表结构

#### items 表（固定项）
- `id`：主键，自增
- `type`：枚举（'app', 'file', 'folder', 'url'）
- `name`：显示名称
- `path`：文件路径或URL
- `icon_path`：图标路径（可选）
- `folder_id`：所属文件夹ID（外键，可为空表示根目录）
- `sort_order`：排序顺序
- `created_at`：添加时间

#### folders 表（文件夹）
- `id`：主键，自增
- `name`：文件夹名称
- `parent_id`：父文件夹ID（外键，可为空表示根目录）
- `sort_order`：排序顺序
- `created_at`：创建时间

### 3.2 关键特性
- 支持多级文件夹嵌套（通过 parent_id 自引用）
- 每个固定项属于一个文件夹（通过 folder_id）
- 排序通过 sort_order 字段实现，支持拖拽更新

## 4. 筛选功能设计

### 4.1 类型筛选
类似搜索模块的 FILTERS，提供预设筛选器：
- 全部（显示所有固定项）
- 应用（type='app'）
- 文件（type='file'）
- 文件夹（type='folder'）
- URL（type='url'）

### 4.2 名称搜索
在筛选结果中支持按名称搜索，使用 SQL LIKE 查询

### 4.3 排序选项
支持按名称、添加时间、文件大小等排序

### 4.4 筛选UI
在界面顶部提供筛选按钮组，点击切换筛选类型，同时显示搜索框

## 5. 前端设计

### 5.1 主窗口页面布局
- 顶部工具栏：视图切换按钮（网格/列表）、筛选器按钮组、搜索框
- 内容区域：显示固定项，支持拖拽排序
- 底部状态栏（可选）：显示固定项总数

### 5.2 弹窗布局
- 紧凑型设计，仅显示最常用的固定项
- 支持搜索和快速筛选
- 网格视图为主，节省空间

### 5.3 视图切换
- 网格视图：图标+名称，类似Windows开始菜单
- 列表视图：详细信息，包含名称、路径、类型、添加时间
- 切换按钮在工具栏，状态保存在配置中

### 5.4 拖拽排序
- 使用 @dnd-kit 实现拖拽排序
- 网格视图：拖拽图标调整位置
- 列表视图：拖拽行调整顺序
- 排序结果实时保存到数据库

### 5.5 右键菜单
- 调用Windows系统原生右键菜单
- 包含打开、删除、重命名、属性等选项
- 与Windows 11桌面右键菜单风格一致

### 5.6 交互流程
1. 添加固定项：右键点击项目 → 选择"固定到快速启动"
2. 移除固定项：右键点击项目 → 选择"从快速启动移除"
3. 创建文件夹：工具栏点击"新建文件夹"按钮
4. 移动到文件夹：拖拽项目到文件夹，或右键选择"移动到文件夹"

## 6. 集成方案

### 6.1 模块注册
- 创建 `src-tauri/modules/quicklaunch/manifest.json`
- id: "quicklaunch"
- name: "快速启动"
- icon: "layout"
- enabled: true
- default_config: { view_mode: "grid", sort_by: "name", sort_desc: false }

### 6.2 Rust 后端结构
```
src-tauri/src/modules/quicklaunch/
├── mod.rs          # 模块入口，setup 函数
├── commands.rs     # IPC 命令（添加/删除/排序固定项）
├── db.rs           # SQLite 数据库操作
└── types.rs        # 数据类型定义
```

### 6.3 前端组件结构
```
src/modules/quicklaunch/
├── Page.tsx        # 主窗口页面
├── Settings.tsx    # 设置组件
├── GridView.tsx    # 网格视图组件
├── ListView.tsx    # 列表视图组件
├── FilterBar.tsx   # 筛选工具栏
└── ItemCard.tsx    # 单个固定项组件
```

### 6.4 与现有模块交互
1. **剪贴板模块**：可以从剪贴板历史中固定项目
2. **搜索模块**：可以固定搜索结果
3. **文件操作**：复用现有文件打开、图标获取命令

### 6.5 配置管理
- 视图模式、排序方式等配置保存在 `config.json` 的 `modules.quicklaunch` 中
- 固定项数据保存在 SQLite 数据库中
- 窗口尺寸记忆（弹窗）

### 6.6 热键集成
- 集成到统一热键系统（`unified_hotkey`）
- 热键呼出弹窗，类似剪贴板和搜索模块
- 支持独立热键配置（当 `unified_hotkey=false` 时）

## 7. 开发步骤

1. 创建 manifest.json
2. 实现 Rust 后端（数据库、命令）
3. 实现前端组件
4. 在 lib.rs 和 App.tsx 中注册
5. 测试和调试

## 8. 注意事项

1. **性能考虑**：大量固定项时需要分页加载
2. **图标缓存**：缓存获取的图标，避免重复请求
3. **错误处理**：文件不存在、URL无法访问等异常情况
4. **数据迁移**：支持从旧版本迁移数据
5. **国际化**：支持多语言（可选）
