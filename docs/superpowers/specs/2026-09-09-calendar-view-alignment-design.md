## 1. 背景与目标

日程表模块已有 月 / 周 / 日 / 时间线 / 待办 五个视图。经与参照项目逐行对照（见附录 A），发现我们缺的不是骨架，而是**「一眼看出状态」的表达**：参照项目的事件卡片会说话（进行中 / 已结束 / 进度条 / 下一节课），我们的只是一块静态色块。

本设计的目标：**把参照项目那套信息表达与交互对齐过来，但不动我们的布局骨架**。

用户已确认的三项前提：

| 决策点 | 结论 |
|---|---|
| 对齐深度 | **B 档**：换皮 + 信息呈现与交互；**不动布局骨架** |
| 皮肤 | 结构一律用现有主题变量；强调色默认值改为 `emerald`（整个工具箱一起变绿，设置页可随时改回） |
| 交付方式 | **分两批**，每批独立验收 |

**明确不做**（用户已排除，属 C 档骨架级改动）：

- 不把时间线改成「卡片堆叠」（保留真实时间轴、小时尺、时间比例高度）
- 不把周视图纵向窗口锁死为 08:00–22:00（保留按事件自适应收缩）
- 不引入学期 / 第几周 / 节次概念（我们是非课表型通用日历）
- 不动数据库、不动 Rust 后端（本次全部为前端渲染层改动）

## 3. 设计口径（实现前必须唯一确定）

### 3.1 状态判定

统一由纯函数给出，**以本地时间为准**（沿用项目「本地时间同口径」约定）：

```
给定事件的 start_ms / end_ms 与 now：
  全天事件            → status = 'allday'（不参与进行中 / 进度 / 下一节课）
  now >= end_ms       → status = 'past'，pct = 100
  start_ms <= now < end_ms
                      → status = 'ongoing'，pct = round((now-start)/(end-start)*100)，钳制 0..100
  now < start_ms      → status = 'future'，pct = 0
```

- **只有「今天」才显示状态标**。过去的日子整体算已结束，未来的日子不加标 —— 避免满屏标签。
- 跨午夜事件（end 早于 start，如 23:00→次日 01:00）按当日可见段参与计算：`end` 钳制到当日 24:00，进度按钳制后的区间算。
- 进度每分钟刷新一次（复用 `views.tsx` 现有 `useNow`，60s 一跳）。

### 3.2 下一节课（「下一个即将开始」）

- 取**今天**时间上最近的一条 `status === 'future'` 的**分时**事件（全天事件不参与）。
- 正在进行时返回其后的下一条；课间时段仍返回即将开始的那条；今天没有更多 → 不高亮。
- 高亮方式：该事件的地点文字（有地点）或标题（无地点）用主色加粗。

### 3.3 状态表达的落地范围（关键取舍）

| 视图 | 1 状态标（进行中 / 已结束） | 2 进度填色 | 3 下一节课 | 已结束灰化 |
|---|---|---|---|---|
| 时间线 | 仅「今天」 | 仅「今天」 | ✅（仅「今天」） | 今天之前的所有日子：灰底灰字（丢掉课程色） |
| 日视图 | 当天就是今天时显示 | 同左 | ✅（当天就是今天时） | 当天在今天之前时 |
| 周视图 | ❌ 不做 | ✅ 仅「今天」列 | ✅（仅「今天」列） | ❌ 不做 |

**为什么周视图不做状态标 / 灰化**：卡片尺寸小，塞标签会挤掉课名；且周视图可翻到过去任意一周，若整体灰化会出现「整屏灰」的观感（参照项目的周视图本身也没有状态标和灰化，只有时间线有）。周视图只保留「今天这一列」的进度表达。

### 3.4 过去折叠（时间线）

- 时间线已加载的日子里，`dayKey < 今天` 的日期收进一个折叠容器，头部文案「已结束 · 过去 N 天」，右侧「展开 / 收起」。
- 默认**收起**；展开状态不持久化（每次进入时间线重新收起）。
- 与「跳过空闲」开关**互不影响**：折叠只改变过去日子的可见性，跳过空闲仍按原规则跳过无事件的日子。
- 折叠**不阻断向上加载**：折叠容器内仍按现有逻辑继续向上滚加载更早的日子（`onLoadEdge('up')` 不变）。
- 连点保护：折叠/展开的重绘合并（参照项目同款做法，260ms 窗口），避免一次性挂载大量节点时卡顿。

### 3.5 滑动切周（周视图）

- 触发方式（三条并存）：横向滚轮 / 触控板横扫、按住鼠标左右拖动、顶部箭头 + 日期选择器（保留）。
- 阈值：拖动位移超过容器宽度的 12% 或速度足够快才切周，否则回弹 —— 避免与周视图纵向滚动打架。
- 切换方向：右滑 = 上一周，左滑 = 下一周；切换时沿用现有的视图切换动画类（`animate-in slide-in-from-*`）。
- 若手势与纵向滚动冲突无法稳定解决，**降级方案**：只保留触控板横扫 + 箭头，去掉鼠标拖动（在实施报告中说明）。

### 3.6 字号自适应（周视图事件块）

按卡片实际宽度与高度分档（纯函数给出，便于单测）：

| 条件 | 表现 |
|---|---|
| 宽度 < 90px | 标题字号降一档 |
| 高度 < 34px | 只显示标题（隐藏时间 / 地点 / 备注） |
| 高度 < 54px | 显示标题 + 时间，不显示地点 / 备注 |
| 地点文本超宽 | 单行截断（不换行、不折行） |
| 宽度 < 70px 且高度 < 54px | 标题最多 2 行，超出省略号（这是对「标题永不截断」的唯一例外，仅限极窄卡片） |

现有分档规则（标题永不截断、高度 ≥54 显示时间地点、≥80/110 追加备注行）**保留**，本项只在其上补「按宽度缩字号 + 地点不换行」，并对极窄卡片开一个标题截断的例外。

### 3.7 备注圆点（周视图）

- 事件有备注（`notes` 非空）时，卡片右下角显示一个主色小圆点（4px），不占文字空间。
- 鼠标悬停浮层（现有 `EventBlock` 的 portal 浮层）继续显示备注全文，两者不冲突。

### 3.8 今日列贯通高亮（周视图）

- 表头的今天列与网格中的今天列共用同一底色，中间的分隔线不打断高亮（做法：在表头行与网格列各自铺同色背景，并让中间那条 `border-b` 只画在非今天列上）。
- 表头里今天日期的主题圆底保留（现有行为不变）。

### 3.9 皮肤（强调色默认 emerald）

- 日历模块内**一律使用主题变量**（`--primary` / `--muted` / `--border` 等），不硬编码颜色。
- 全局强调色默认值由「默认（蓝紫）」改为 `emerald`：未显式选过强调色的用户启动后整个工具箱为薄荷绿；**已显式选过强调色的用户保持原选择**。
- 设置页「强调色」选项不变，用户可随时改回默认 / sky / violet / amber。
- 深浅主题自动兼容（emerald 的 OKLCH 值深浅两套通用，已在 `lib/theme.ts` 中定义）。

## 5. 边界与容错

- 事件时长为 0（start == end）：不算进行中，直接按 `past`/`future` 判定，进度恒 0 或 100，避免除零。
- 事件数据异常（`start_ms`/`end_ms` 非数字）：跳过状态计算，按普通色块渲染。
- 今天没有任何分时事件：不显示下一节课高亮，时间线仍显示「今天 · 无课」占位（现有行为）。
- 折叠容器为空（今天之前没有已加载的日子）：不显示折叠条。
- 横向手势与纵向滚动冲突：按 3.5 的降级方案处理。
- 深色模式下进度填充、灰化、今日列高亮：全部走主题变量，不做硬编码白色/黑色叠加。
